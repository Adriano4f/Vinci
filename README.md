# Vinci Web Studio

Static website of **Vinci Web Studio**: websites for small businesses and
custom physical products (posters, magnets, printed frames, jewelry).

- Live: <https://vincihost.vercel.app>
- Full technical documentation: [`docs/REFERENCE.md`](docs/REFERENCE.md)
  (build pipeline, deployment, runtime model, language semantics, browser
  APIs and per-module specification; no prior TypeScript/JavaScript
  knowledge assumed)

## Stack

HTML documents + CSS + TypeScript compiled to JavaScript. No framework, no
bundler, no server, no database. Hosted on Vercel as static files.

```
src/*.ts ──tsc──▶ js/*.js (+ .js.map) ──build-static.mjs──▶ dist/ ──Vercel──▶ vincihost.vercel.app
```

Edit `src/*.ts`, never `js/*.js`: `js/` is regenerated by every build. It is
committed so the repository root also works as a site without building.

## Build

Requires Node.js ≥ 20.

```bash
npm install        # installs typescript into node_modules/
npm run build      # tsc (type-check + emit js/) then assemble dist/
npm run watch      # recompile on save
npm run serve      # serve the repository root over HTTP
npm run preview    # build, then serve dist/ (what Vercel deploys)
```

A new top-level file or directory is deployed only if it is added to the
`files`/`dirs` arrays in `scripts/build-static.mjs`.

## Deployment

`main` of `Adriano4f/vincihost` deploys to production; each pull request
gets a preview URL. `Adriano4f/Vinci` holds the same code; apply every
change to both repositories.

## Common edits

| Change | File(s) | Locate |
|---|---|---|
| Plan text and prices | `index.html` | `class="offer"` (one card per plan) |
| Plan limits, "what is a page" | `index.html` | `class="plan-terms"` |
| Plan options in the form | `contact.html` | `<option value="basic">` |
| Add a poster | `servicios/posters.html` | Duplicate an `<article class="card poster-card reveal">`; image in `img/servicios/posters/` |
| Poster price | `servicios/posters.html` **and** `src/pedido.ts` | `RD$250` (the `.ts` uses it in the pre-filled order message) |
| Colors | `css/main.css` | `:root` custom properties; `--accent` is the brand navy |
| Gallery card | `templates.html` | `<article class="card template-card" data-category="…">` |
| Form recipients | `src/contact.ts`, `src/pedido.ts` | `const recipient` |
| WhatsApp number | `src/contact.ts`, `src/pedido.ts`, `contact.html`, `servicios/pedido.html` | `18298591920` / `829) 859-1920` |
| Link-preview image | `img/og-vinci.jpg` | 1200 × 630 |

Visible site text is Spanish; identifiers and code comments are English.
